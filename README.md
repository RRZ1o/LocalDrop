RRZ1o // LocalDrop

Fast and private file sharing for Termux & Linux.

Features

* Modern Web UI
* Drag & Drop uploads
* Multiple file upload
* Upload progress
* File search
* Download & Delete
* SHA-256 verification
* Access Token
* 10 GB maximum file size
* Termux support
* Linux support
* Responsive design

Installation

git clone https://github.com/RRZ1o/LocalDrop.git
cd LocalDrop

Run

Linux

python3 localdrop.py

Termux

python localdrop.py
